Telemetry filters

A message body matching any enabled pattern is dropped before storage — uptime strings, tracker health blocks, weather summaries, bare numeric series. Callsigns are validated separately; these rules work on what the message says.

Saving or enabling a rule also deletes the stored messages it matches, so the archive reflects the rule immediately rather than only for new traffic. A disabled rule touches nothing.
